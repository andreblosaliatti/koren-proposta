# Koren 90 — Proposta Inflow IA

Site estático da proposta de três meses para Koren Cosméticos.
Inclui os efeitos de movimento e brilho da versão final.

## Arquivos

- `index.html`: conteúdo, estilos e animações do site.
- `asset-0.png` e `asset-1.png`: imagens da marca utilizadas pela página.
- `.nojekyll`: desativa o processamento Jekyll no GitHub Pages.

## Ver no computador

Extraia o ZIP e abra `index.html` no navegador. Mantenha as imagens junto ao HTML.
Não precisa de npm, instalação de dependências ou build.

## Colocar no GitHub

1. Crie ou abra o repositório desejado.
2. Extraia o ZIP e envie os arquivos para a raiz do repositório, incluindo as imagens.
3. Faça o commit. Não envie apenas o ZIP: envie os arquivos extraídos.

## Publicar no GitHub Pages

1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment → Source**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)` e clique em **Save**.
4. Aguarde a publicação e abra o endereço apresentado pelo GitHub.

Documentação: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Editar

Altere os textos e o CSS dentro de `index.html`.
Os três links do Instagram permanecem na seção de portfólio.
Os links para o site da Inflow IA foram retirados.
